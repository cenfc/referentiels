## Résumé
Le package `referentiels` offre l'accès à des référentiels internes/privés aux Conservatoires d'Espaces Naturels de Bourgogne et de Franche-Comté.

## Installation
Les commandes à utiliser pour installer le package sont les suivantes :
``` r
install.packages("pak")
pak::pak("cenfc/referentiels")
```

## Recevoir de l'aide
Si vous rencontrez un bug clair, merci de créer un ticket avec un exemple minimal reproductible sur [GitHub](https://github.com/cenfc/referentiels/issues).
